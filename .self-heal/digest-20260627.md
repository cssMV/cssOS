## ② 真实 bug + 根因 + 建议 diff + 风险

### Bug A —（**唯一干净的前端代码 bug**）评论 API 打到 `#` 占位 id → 404
- **指纹** `1da736d3…`，count 132，**今天仍在发**（06-27 12:36）。
- **根因**：`public/app.person-mv-comments-share.js` 的 `open(mvId)` 只挡 `if (!mvId) return;`，但占位字符串 `"#"` 是 truthy（多半来自 `href="#"` 锚点被当成 mvId 读出），于是 `fetchComments("#")` → `/api/person-mv/mvs/%23/comments` → 404。与既有铁律一致（占位 id 如 `workId="#"` 必须在 fetch 前拦掉）。
- **建议 diff**（已在 scratchpad 副本 `node -c` 通过，SYNTAX_OK）：

```js
// public/app.person-mv-comments-share.js

// 新增工具函数（放在 open 之前）
function isValidMvId(id) {
  id = String(id || "").trim();
  return !!id && id !== "#" && id !== "undefined" && id !== "null";
}

// fetchComments (≈ line 247) 入口加守卫
async function fetchComments(mvId) {
  if (!isValidMvId(mvId)) return { items: [], summary: null };   // ← 新增
  var r = await fetch("/api/person-mv/mvs/" + encodeURIComponent(mvId) + "/comments?limit=50", { credentials: "include" });
  ...
}

// open (≈ line 465) 守卫从 !mvId 升级
async function open(mvId) {
  if (!isValidMvId(mvId)) return;   // ← 原: if (!mvId) return;
  ...
}
```

- **风险：低**。只把明显非法的占位 id 提前 return，真实 id（UUID/数字）不受影响。无 i18n/无样式/无画音分层影响。
- **部署提醒（待 Jing 手动）**：前端改动 → 需重打包 bundle + bump sw + rsync public/ 到 `/srv/cssos/current/public/`，否则线上不生效（见铁律「工作三部曲」「Deploy public/ assets separately」）。
