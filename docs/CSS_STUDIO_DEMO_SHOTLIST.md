# CSS Studio — 60-Second Demo · Shot-by-Shot Script

**Purpose:** the ONE asset that carries the YC app, Product Hunt, and all investor emails.
**Rule:** show, don't tell. The app's own **sound** is the star — keep MV audio; use short text
captions instead of a heavy voiceover. Never show a spinner for more than ~1s (jump-cut the waits).

**Format:** record landscape **1920×1080 (16:9)** for YC/PH/email. (Also grab a vertical
**1080×1920** cut of shots 1–3 for TikTok/Reels/Shorts — see bottom.)

---

## Pre-production checklist (do this BEFORE hitting record)
- [ ] Pick a **gorgeous hero work** to open on (strong cover, good song, emotion-subtitle burst looks great).
- [ ] Have a **short, punchy prompt** typed out ready to paste (e.g. `a neon dynasty queen, defiant, guzheng + trap`).
- [ ] Pre-generate the create-demo work so the result is ready — you'll **jump-cut** the wait, not wait live.
- [ ] Load a work that already has **2+ languages** so the "add a language" tap is instant.
- [ ] Full screen, notifications off, clean status bar, brightness up, **audio on and levels good.**
- [ ] Screen-record at 60fps if possible; cursor visible only when tapping.
- [ ] Optional: one short **Vision Pro / Apple TV** clip for the "every screen" beat.

---

## THE SCRIPT (60.0s)

### 🎬 Shot 1 — Cold open: "it just plays" (0.0 – 8.0s)
- **Visual:** Black for 0.5s → open CSS Studio → a fully-produced MV is **already playing**,
  full-screen, emotion-subtitle bursting. No menus, no tap.
- **Audio:** **MV sound, full.** Let it breathe. No voiceover.
- **Text overlay (in, 3.0s):** small, lower-third → `No tap. No mute. It just plays — with sound.`
- **Note:** This is the whole pitch in 8 seconds. Don't rush it. Let a viewer *feel* the "wow, it's alive."

### 🎬 Shot 2 — The problem, fast (8.0 – 13.0s)
- **Visual:** Quick split/caption card over the still-playing MV (audio ducks slightly, keeps going).
- **Text overlay:** `Suno makes the song. Sora makes the clip.` → (1.5s) → `Nobody made a place to WATCH it.`
- **Audio:** MV audio continues low under the text.
- **Note:** Only 5s. Two lines. Then back to product.

### 🎬 Shot 3 — In-cinema CREATE (13.0 – 30.0s)
- **Visual:** Tap the in-cinema assistant → paste the ready prompt → hit go →
  **jump-cut** the generation (max 1s of a tasteful progress beat) → the new MV **plays in the SAME panel**.
- **Audio:** New work's sound comes up as it starts.
- **Text overlay (during type):** `Type one line…` → (on result) `…it plays right here.`
- **Note:** The magic is that you **never leave the cinema**. Emphasize the same-panel result.
  Cut the real wait ruthlessly — result must feel near-instant.

### 🎬 Shot 4 — The MOAT: any language, one tap (30.0 – 44.0s)
- **Visual:** On a playing work, tap the **"add a language / multilingual"** capsule → pick a
  second language → **same visuals, new voice/language** starts singing. (If possible show a 3rd.)
- **Audio:** Language A for ~2s → switch → Language B, clearly different voice, **same picture.**
- **Text overlay:** `Same film. Any language. One tap.`
- **Note:** This is the defensible insight — visuals stay, audio is a separable layer. Make the
  *audio change* audible and obvious while the *picture is identical*.

### 🎬 Shot 5 — Breadth montage (44.0 – 53.0s)
- **Visual (fast cuts, ~1.5s each):**
  1. Emotion-subtitle **burst** signature (a big beautiful moment).
  2. In-panel **marketplace / share** (a work as a tradeable/shareable asset).
  3. **Every screen:** iPhone → Apple TV → Apple Watch → **Vision Pro spatial cinema**.
- **Audio:** A single continuous music bed across the cuts (one work's audio, not chopped).
- **Text overlay (one line, holds):** `Watch. Create. Trade. On every screen.`
- **Note:** Rhythm to the beat. This shows depth without slowing the story.

### 🎬 Shot 6 — Close (53.0 – 60.0s)
- **Visual:** Cut to the hero MV playing again for 1.5s → fade to logo on black.
- **Text overlay:** Logo → `CSS Studio` → tagline `Open the app — and it plays.` → `[cssstudio.app]`
- **Audio:** Let the last musical phrase resolve, then a clean button/sting.
- **Note:** End on the product feeling, not a slide. Last frame = logo + URL, hold 2s.

## Editing & delivery notes
- **Captions:** clean sans, bottom third, high contrast, generous safe-margins. Keep ≤6 words/line.
- **Pace:** cut on the beat; no shot longer than 8s except Shot 1. If it drags, trim Shot 5 first.
- **Waits:** any generation/loading > 1s = **speed-ramp or hard cut.** Never a naked spinner.
- **Music continuity:** let real MV audio carry Shots 1–4; single continuous bed for Shot 5.
- **Export:** H.264 MP4, 1080p, ~10–20 Mbps. Also export a muted-friendly version with burned
  captions (some feeds autoplay muted — captions must tell the story silently too).
- **Vertical social cut (15–30s):** just Shots 1 → 3 → 4 (open-plays → type-a-line → change-language),
  1080×1920, big captions — that's the TikTok/Reels/Shorts hook that drives the organic loop.

## Where each version goes
- **60s landscape** → YC demo field, Product Hunt gallery slot #1, investor emails https://youtu.be/g-9L4zG5lKI.
- **15–30s vertical** → TikTok / Reels / Shorts / X — the top-of-funnel that points back to the app.
