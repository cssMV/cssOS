# CSS Studio — Personalized Outreach Email Templates

**You send these yourself.** Fill every `[bracket]`. Rules that make cold/warm emails work:
- **Short** (under 120 words). Investors skim on phone.
- **One ask**, one link. The product demo does the convincing — lead people to it.
- **Personalize the first line** (why *them* specifically) — never paste a generic blast.
- **Subject line matters most.** Keep it concrete and curious.
- Best path: get a **warm intro**; use the "ask for intro" template with your network first.

---
