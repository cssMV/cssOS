# Real Person → Castable Digital Actor · Pipeline Spec
# 真人 → 可上架数字演员 · 管线技术方案

> Capture · Face · Voice · Perform  ｜ 采集 · 造脸 · 克隆声 · 出演
> Status: v0.1 draft. MVP can ship now at near-zero new cost; the only hard cost/blocker is singing-voice cloning (needs GPU) — deferred to v3, non-blocking.
> 状态:v0.1 草案。MVP 现在即可上线、几乎零新成本;唯一真花钱/真门槛是"本人歌声克隆"(要 GPU),放到 v3、非阻塞。

Architecture constitution: **self-hosted engines + kie as the only third-party gateway; all outputs to R2; generation always paid by the user.**
架构宪法:**自家引擎 + kie 唯一第三方网关;产出全落 R2;生成永远用户付。**

## The 5 phases ｜ 五步管线

### Phase 0 — Capture ｜ 采集 · 引导式表情采集表  ✅ *UI shipped (v838)*
Not one long take — a **Vision Pro–style guided sequence**: the app prompts each pose one at a time (~1.5s each, 3-2-1 countdown, auto-snaps a frame), finish one to advance, restart anytime. ~30–45s total.
不是一条长视频 —— **Vision Pro 式引导流程**:App 逐个提示(每个约 1.5 秒、3-2-1 倒数、自动抓帧),完成一步进下一步,随时可推倒重录。约 30–45 秒。

Four layers ｜ 四层:
1. **Geometry / liveness ｜ 几何/活体** — front · left · right · blink (multi-angle face + anti-spoof) ｜ 正脸·左转·右转·闭眼(多角度建脸 + 防伪)
2. **Emotion range (6 channels, aligned to the emotion-subtitle palette) ｜ 情绪演技(6 通道,对齐情绪字幕情绪库)** — calm / joy / grief / ignite / intimate / resolve
3. **Villain ｜ 反派** — cold sneer / menacing ｜ 冷笑 / 狞笑
4. **Free grimace ｜ 自由鬼脸** — a spontaneous face; very hard for AI to fake = strong anti-spoof ｜ 即兴鬼脸,AI 极难伪造 = 强防伪

Voice: read the consent line, then hum/sing a few notes. **It need not sound good — we just need a *singing-voice sample*.** ｜ 声音:照读授权词,再随便哼唱几句。**不要求好听 —— 只需一段"歌声"样本。**

**UX law: every step tells the user *why* it's needed — it must feel like a required part of the process, never harassment or a runaround.**
**UX 铁律:每一步都告诉用户"为什么必须这么做" —— 要让人觉得是必须的流程,绝不是刁难或耍猴。**

### Phase 1 — Verify + asset prep ｜ 核验 + 素材清洗  🔨 *frames→face done (v839); manual verify exists*
- Liveness: v1 = admin manual review (video + random grimace confirms live human). Automated liveness (3rd-party) → v4.
  活体:v1 人工审核(视频 + 随机鬼脸格确认真人);自动活体(第三方)放 v4。
- Asset prep: on signup the captured frames are promoted → `reference_images` + `cover_image` (front frame, face-focal centered). The real-person actor is **immediately castable** — no GPU.
  素材清洗:签约时采集帧自动落 `reference_images` + `cover_image`(正脸帧、face-focal 居中),真人演员**立即可被选用** —— 无需 GPU。

### Phase 2 — Identity assets ｜ 形象资产 · 参考脸 + 封面  🔨
Reference face = the person's **own consented real frames** (no synthetic face —保真 + 合规). Optional nano-banana polished cover (¢3, keeps the person's likeness). Optional TripoSR 3D bust.
参考脸 = 本人**已授权的真实帧**(不另造合成脸,保真+合规)。可选 nano-banana 精修封面(¢3,保持本人相貌)。可选 TripoSR 3D 半身像。
> Compliance red line: real-person actors use only their own consented frames — **never** feed A's capture into B's face; watermark + `fingerprint_hash` on every output.
> 合规红线:真人只用本人授权帧,**绝不**把 A 的采集喂成 B 的脸;产出打水印 + 指纹。

### Phase 3 — Voice clone ｜ 声音克隆  ⚠️ *has a threshold · deferrable*
- Speech: XTTS-v2 self-hosted, runs on CPU (slow but free) — enough for dialogue.
  说话:XTTS-v2 自托管,CPU 能跑(慢但免费)—— 对白够用。
- Singing: RVC / so-vits-svc, realistically **needs GPU** (we can't get L4/T4 yet).
  歌声:RVC / so-vits-svc,现实里**需要 GPU**(暂时拿不到 L4/T4)。
- **MVP workaround:** the song is still generated by Suno (generic voice); omnihuman makes the person's face **lip-sync** the singing. Viewers see "the real person singing"; the voice is Suno's. Real own-voice singing lands once GPU is available.
  **MVP 过渡:** 歌本体照常 Suno 生成(通用声线),用 omnihuman 让本人的脸**对口型**演唱。观众看到"本人在唱",声线是 Suno 的。等有 GPU 再上真·本人歌声。

### Phase 4 — Perform ｜ 出演渲染 · 会演的脸  ✅ *engines in place (omnihuman/seedance); wiring pending*
On cast: audio (Suno song / cloned voice) + the person's reference & anchor frames → **omnihuman** talking/singing lip-synced video; narrative shots → **seedance/veo**. Each segment picks the emotion **anchor frame** that matches the emotion-subtitle emotion, so the actor "acts" across the whole song. Output → R2, into the unified cinema render.
被选用时:音频(Suno 歌 / 克隆声)+ 本人参考帧与锚点帧 → **omnihuman** 对口型演唱视频;叙事镜头 → **seedance/veo**。每段按情绪字幕的情绪挑对应**锚点帧**,让演员在整条曲子上"演"。产出落 R2,进影院统一渲染。

### Phase 5 — Governance ｜ 治理 · 贯穿全程  ✅ *mostly shipped*
Consent records (`actor_consents`), revoke/takedown anytime, own works free to watch, misuse reporting — **already live**. Plus: capture frames private-R2-only & used only for that actor; watermark + fingerprint on outputs; public figures need agency verification.
授权记录、随时撤权下架、参演作品本人免费欣赏、举报滥用 —— **已上线**。补:采集帧仅私有 R2、仅本人演员用;产出打水印+指纹;公众人物需经纪核验。

## Cost model ｜ 成本模型

**Platform · one-time per actor (onboarding) ≈ ¢3** ｜ **平台 · 每位演员一次性(入职)≈ ¢3**
- keyframe + face-focal: self-hosted, free ｜ 抽帧 + 人脸对齐:自托管,免费
- optional polished cover: nano-banana ¢3 (skip → $0) ｜ 精修封面:nano-banana ¢3(可跳过则 $0)
- speech voice clone: self-hosted CPU, free (compute = time) ｜ 说话声克隆:自托管 CPU,免费(算力=时间)
- manual verify: labor, not cash ｜ 人工核验:人力,非现金

**User · per performance (COGS) = $ per clip** ｜ **用户 · 每次出演(COGS)= $ 按条**
- omnihuman lip-sync video / seedance-veo shots / Suno song — all via kie, user pays (pricing constitution: generation is never free).
  omnihuman 对口型 / seedance·veo 镜头 / Suno 歌 —— 全走 kie、用户付(定价宪法:生成永远用户付)。

**Only new cash outlay = the GPU for singing-voice cloning (Phase 3b). MVP bypasses it entirely → v1 launches at ~zero new cost.**
**唯一新增现金支出 = 歌声克隆的 GPU(Phase 3 后半)。MVP 完全绕开它 → v1 上线几乎零新成本。**

## Risks & open decisions ｜ 风险 & 待定决策
- **No GPU → singing-voice clone stalls.** Fix: MVP uses Suno voice + lip-sync; rent GPU per-job later, or make own-voice singing a paid premium unlock.
  **拿不到 GPU → 本人歌声克隆卡住。** 解:MVP 用 Suno 声+对口型;歌声克隆按需租 GPU,或做成付费高级档。
- **Auto liveness vs manual.** v1 manual (cheapest, most robust); wire the interface so v4 can switch to a 3rd-party provider.
  **自动活体 vs 人工。** v1 人工(最省最稳);埋好接口,v4 切第三方。
- **Own voice vs borrowed voice.** In v1 viewers see "the person singing" but the voice is Suno's — label it clearly on the consent page: *"Likeness is you · voice is AI-generated."*
  **本人声 vs 借声。** v1 观众看"本人在唱"但声是 Suno 的 —— 授权页明确标注:*"形象为本人 · 声线为 AI 生成"。*
- **Likeness compliance.** Revoke/report already exist; anti-deepfake defense = watermark + fingerprint + frames-never-reused-across-actors.
  **真人肖像合规。** 撤权/举报已有;防换脸滥用 = 水印 + 指纹 + 采集帧绝不跨演员复用。

## Roadmap ｜ 分期路线
- **v1 · MVP (can start now):** guided expression capture → keyframes → reference face → omnihuman lip-sync (Suno voice) + manual verify. Real-person actor is listable & castable. ~zero new cost.
  **v1 · MVP(可先开工):** 引导采集 → 抽帧 → 参考脸 → omnihuman 对口型(Suno 声)+ 人工核验。真人演员可上架、可被选用。几乎零新成本。
- **v2:** speech voice clone (XTTS self-hosted) → dialogue works use the person's **real voice** speaking.
  **v2:** 说话声克隆(XTTS 自托管)→ 对白类用**本人真嗓**说话。
- **v3 · needs GPU:** singing voice clone (RVC/so-vits + rented GPU) → the person **sings in their own voice**, as a paid premium tier.
  **v3 · 需 GPU:** 歌声克隆(RVC/so-vits + 租用 GPU)→ 本人真嗓**唱歌**,付费高级档。
- **v4 · scale:** automated liveness (3rd-party) replaces manual review to support sign-up growth.
  **v4 · 规模化:** 自动活体(第三方)替换人工,支撑签约量增长。
