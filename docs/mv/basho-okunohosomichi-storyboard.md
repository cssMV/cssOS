## 〇 · 与《辋川》必须一眼分得开

两部都是「山水为主、脸不吃重」,所以**必须在观感上刻意拉开**,否则会被看成同一部:

| | 《王维 · 辋川》 | 《芭蕉 · 奥の細道》 |
|---|---|---|
| **招牌运动** | 极缓**横移**(手卷展开) | **极缓推 + 完全定格**(俳句是截取瞬间) |
| **色板** | 石青 / 苔绿 / 月白 | **墨黑 / 苔緑 / 雪白**,第三部加**天河的银** |
| **组织轴** | 人间 → 独处 → 空(**人物递减**) | 地 → 石 → 宇宙(**尺度扩张**) |
| **人物** | 一二部远景剪影,第三部**无人** | 三部**皆有**斗笠旅人剪影,但永不超过 1/8 宽 |
| **气质** | 静(禅坐) | 旅(行脚) |
| **文明** | 中华 · 唐 | **日本 · 江戸** |

**「极缓推 + 定格」是本片的签名。** 王维是把画卷横着拉开;芭蕉是**站定、凝视、按下**。
横移在本片**每部限用 2 次**,只给"行路"的镜头。

### 双锚

**锚 A ·「地貌锚」(三部全片引用)**
> 日本東北の山中、元禄年間。手前は苔むした濡れた岩と深い夏草、中景は真っ直ぐな
> 杉の林、遠景は霧に切られた三重の低い山並み。墨黒・苔緑・雪白の三色のみ。
> 暖色なし、人工の灯なし。長玉の圧縮、広角の歪みなし。
> 空は上三分の一、右半分は霧の余白。写実的な映画の質感、冷たく抑えた諧調。
> 人物なし、建物なし、現代的な物は一切なし。文字なし。

**锚 B ·「旅人锚」(三部皆可用,但只作剪影)**
> 元禄期の旅の俳人。菅笠、墨染めの粗い旅衣、脚絆、杖ひとつ。**背中のみ、顔は完全に不可視**。
> 画面の八分の一を超えない大きさで、深い草か杉林の縁に立つ。自然光のみ。長玉、浅い被写界深度。
