## 零 · 这一部的规矩只有一条

# 镜头就是那朵云。全片只有开头 18 镜在地面, 此后 147 镜一次不落地。

《云使》整首诗就是夜叉在告诉云该怎么飞 —— 飞过哪条河、绕过哪座山、
在哪座城上空停一停。**运镜不是我加的, 运镜是原文。**

所以这一部把「不落地」当成硬约束, 而不是风格偏好:

| | |
|---|---|
| 一部 1–18 镜 | **全片仅有的地面镜头**。夜叉在罗摩山上, 抬头。 |
| 一部 19 镜起 | 镜头升空。**从此再没有一个镜头的机位在地面。** |
| 二部 全部 | 高空飞行。人、村、城都在下面, 越来越小。 |
| 三部 全部 | 仍在空中 —— 但可以**降到窗口高度悬停**。悬停不是落地。 |

「降下来看她」和「落到地上」是两件事。云可以贴着窗子, 不能站在院子里。
**任何一镜写成地面视角, 就是把这一部的立意拆了。**

## 二 · 全片硬约束(每镜都发)

1. **笈多王朝的印度, 不是后世的莫卧儿。** 建筑是**砂岩与砖**, 曲拱(chaitya arch)、
   叠涩穹顶、石刻。**没有洋葱顶, 没有尖拱, 没有白大理石镶嵌** —— 那些晚了一千年。
2. 衣物是**未缝合的织物**: 女子 sari / 男子 dhoti + 上巾, 棉与丝, 靛蓝、姜黄、茜红。
   金饰、臂钏、脚铃。**没有纽扣, 没有立领, 没有缝制的紧身上衣。**
3. 器物: 陶、青铜、木、贝叶。灯是**浅陶碟明火**。乐器只有维那琴、竹笛、双面鼓。
4. 植物是印度季风带的: 芒果、菩提、榕树的气根、莲、伽昙花、茉莉。
5. 动物: 孔雀(季风的信号)、天鹅、牛、象。**孔雀开屏只在雨前。**
6. 一律无字幕、无水印、无文字。
7. **物理常识**: 人不会飞、不站水面、五指、影子同向。**云可以, 人不可以。**

## 三 · 在场标记(第四列 · W2018 起写进表里, 不再用正则猜)

| 标记 | 含义 |
|---|---|
| `无` | 画面里一个人也没有 |
| `女` | 有且只有一位女子, **完整的人**(头/脸/颈/肩/双臂/双手/双脚俱全且相连) |
| `群` | 一群人(村民/城中女子/农夫), 各自完整 |
| `男` | 那位夜叉, 一位成年男子, 完整 |

**没有第五种。** 不许写「只拍手」「只拍衣」「只拍脚」——
芭蕉那只悬空的手、鲁米那件自己站着的袍子, 都是从这种写法里长出来的。
要局部就写「**中景裁切**, 身体继续延伸出画」。
