# 《Popol Wuj · 玛雅三部曲》分镜脚本

**162 镜 / 870 秒 / 约 3,045 credits ≈ $15.2**(seedance-1.5-pro 3.5 cr/s)
镜头数据在 `docs/mv/maya-shotlist.json`, 由 `scripts/maya-shotlist.py` 生成。

## 零 · 时间轴由构造保证, 不靠事后校对

生成脚本里每一镜的 `start` 是前面所有镜时长的累加, `end = start + duration` ——
**装配铁律「duration = 下一镜 start − 本镜 start」由构造成立**, 脚本跑完自动断言:
接缝异常 0 / 时长只用 4/6/8 / 三部各 54 镜。**不给"事后发现拼错了"留余地。**

## 一 · 分镜表的「人」列 —— 沿用 W2018 的做法

| 标记 | 含义 | 发给引擎的约束 |
|---|---|---|
| `无` | 画面里一个人也没有 | 正面写「此地空无一人 / 方圆几里没有别人」 |
| `人` | 有且只有主角一人, **完整的人** | 头/脸/颈/肩/双臂/双手/双脚俱全且相连 |
| `二` | 双子英雄二人 | 明确两人, **各自完整**, 各自站立 |

**这一列是 W2018 用一次返工换来的**: 当时把有人的镜误判成无人镜, 给它写了
「此地空无一人」, 结果生成出一个不该出现的人。**人物标记必须是表里的一列,
不能靠描述文字里的关键词去猜。**

分布: 一部 人 24 / 无 30 · 二部 二 16 / 无 38 · 三部 人 9 / 无 45。
**女主角在第一部全程在场**(Jing:「要美女主角, 不要苦行僧」), 第三部首尾呼应式回归。

## 二 · 三部的视觉轴

| 部 | 轴 | 主色 | 主角在场 |
|---|---|---|---|
| 一《Xkik'》孕育 | 光**从无到有** | 冥界墨绿 + 骨白 → 出洞后的金白 | **高**(24/54) |
| 二《Xib'alb'a》下降 | 光**退到近黑** | 近黑 + 火把橙 + 球场石灰白 | 双子 16/54 |
| 三《Ixim》重生 | 光**回来** | 破晓金 + 玉米黄 + 雨林翠 | 首尾 9/54 |

**这是七部里第一条闭环轴**: 死亡不是终点, 是玉米入土。第三部第 39-41 镜
(撒种的手 / 下葬的手 / 拍平土面)刻意用**同一双手、同一组动作**拍两件事 ——
这是整部三部曲的题眼。

## 四 · 约束写法 —— 逐镜且正面

**同一个错误栽过四次(最惨一次 78% 的镜违规), 所以这里只写正面表述:**
- ❌「不要出现别人」「只放一个人」 → 引擎会读成「放一个」
- ✅「此地空无一人, 方圆几里没有别人」/「有且只有一位女子, 头脸颈肩双臂双手双脚俱全且相连」

**每一镜都自带约束**, 不靠全局提示词兜底 —— 全局的会被逐镜的覆盖掉。
