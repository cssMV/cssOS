# 《Σαπφώ · 萨福三部曲》分镜脚本

**文明** 古希腊 · 公元前 7–6 世纪 · 莱斯博斯岛(Λέσβος, 米蒂利尼) · **画幅** 32:9 (2560×720)
**引擎** `bytedance/seedance-1.5-pro` · **单镜只能 4 / 6 / 8 秒**

---

## 零 · 这一部的分镜表多了一列「人」—— 这是 W2018 换来的

前一部(鲁米)第三部高潮整段拍坏了: 红袍女子、两个人、**没有人的袍子自己站着**。
根因不是引擎, 是我 —— 我用一条**正则**去猜「这一镜该不该有人」, 而正则里没有
「帽」「袍」「手」「裙裾」。于是「帽子稳定不动 —— 头是轴」被判成【无人镜】,
发出去的约束是 "completely deserted, NOT A SINGLE PERSON"。
可这一镜的全部内容就是一个人的帽子。**分类错了, 约束就发反了。**

**改法: 不再猜。分镜表第四列直接标死。**

| 标记 | 含义 | 发给引擎的约束 |
|---|---|---|
| `无` | 画面里一个人也没有 | 正面写「此地空无一人」+ 明确排除地平线上的人影 |
| `人` | 有且只有萨福一人, **完整的人** | 头/脸/颈/肩/双臂/双手/双脚俱全且相连 |
| `二` | 萨福 + 另外一人(仅一幕宴席用) | 明确两人, 各自完整 |

**没有第四种。** 任何「只拍手」「只拍衣」「只拍脚」的写法一律不许出现 ——
芭蕉那只悬空的手、鲁米那件自己站着的袍子, 都是从这种写法里长出来的。
要局部, 就写「**中景裁切**, 人的身体继续延伸出画」, 而不是「只有手」。

## 一 · 导演阐述 —— 这一部要拍成一部真正的电影

**Jing 的两条定调(2026-08-28):**
> 「请把整首 MV 的剧情编好一点, 神奇一点, 优美一点, 请把画面导演连贯一些,
> 你甚至可以使用人类导演一般很难执导的无人机航拍角度。」
> 「也尽量使用一些文明智能联动的美女主角, 而不是总是用一些苦行僧男主角。」

前三部我犯了同一个保守的错: **怕引擎拍不好人, 就大量拍空景。**
辋川 163 镜里 136 镜无人, 鲁米 163 镜里也是。空景确实安全 ——
但安全不是理由, 那等于承认我们只会拍风光片。

**这一部反过来:女主角在场, 而且她美。** 萨福本人就是文明智能联动最好的载体 ——
她是莱斯博斯岛的女诗人、被柏拉图称作"第十位缪斯"。人物、语言、乐器、服饰、
光的性格, 全部从她这一个人身上长出来。

### 我们能做而人类剧组做不到的事

不需要轨道、吊臂、直升机、封岛许可。**一镜可以从浪尖升到三百米。**
所以这一部大量使用【人类导演很难执导的机位】, 并且写进每一镜:

| 手法 | 用在哪 |
|---|---|
| **出水升空** 镜头从海面下升出水面, 水从镜面淌下, 一路升到崖顶 | 一部 #1 · 三部 #33 |
| **顶视正俯** 正上方垂直下看, 人成为图案的一部分 | 一部 #28(影子朝向不对的那一镜) |
| **穿窗** 从室外一镜穿过窗洞进到室内, 不切 | 二部 #38 |
| **贴海飞行** 离水面半米, 平飞追一道浪 | 二部 #2 |
| **垂直爬升** 从人脸高度一路拉到看见整座岛 | 一部 #55 · 二部 #37 |
| **环绕** 以她为轴 360° 绕行, 背景整个转过去 | 一部 #24 · 三部 #49 |
| **穿顶下降** 从塌掉的屋顶缺口垂直降进废墟内部 | 三部 #21 |
| **时间压缩爬升** 一个不切的上升镜里过去两千六百年 | 三部 #34 |

### 连贯性怎么保证

**同机位回照**是这部片的骨架 —— 每一部都有三镜与另一部的某镜**同机位**,
观众不必被告知也会认出来。三部的最后一镜, 是同一个升空动作的三次重复,
只有光不同: 正午的白 → 夜的黑 → 破晓的金。

**注意 1.5-pro 的边界**(已实测): 它在**一镜之内**守得住同一个人,
**跨镜守不住**。所以同机位靠的是**构图与光**, 不是靠"同一张脸" ——
要求跨镜一致的地方, 一律后期用 ffmpeg 派生, 不指望引擎。

## 四 · 全片硬约束(每镜都发)

1. **公元前 6 世纪的莱斯博斯, 不是雅典白大理石。** 石灰岩与晒干泥砖, 木柱涂**彩**
   (赭红、深蓝), 陶瓦屋顶。
2. 衣物只有**亚麻与羊毛**: 希顿、长披巾, 青铜别针固定。**没有丝绸/纽扣/拉链。**
3. 器物: 陶(黑绘/几何纹)、青铜、木、莎草纸。灯是**浅陶碟明火**, 无玻璃无金属身。
4. 乐器只有里拉、巴比同、双管阿夫洛斯、手鼓。
5. 植物只有地中海的。**没有柑橘, 没有仙人掌。**
6. 无字幕、无水印、无文字。
7. **物理常识**: 人不会飞、不站水面、五指、影子同向。
