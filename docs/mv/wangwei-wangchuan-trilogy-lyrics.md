# 《王维 · 辋川三部曲》歌词 · 京典模版

**文明** 中华文明 · 盛唐 · **人物** 王维(摩诘),诗佛,南宗山水画之祖,晚年隐于辋川
**语言** 中文(母语)· **work_type** `triptych`
**规格** 每部 **10 节 / 50 行**(铁律要求 ≥10 节 / ≥40 行)

**曲风(英文 —— Suno 只认英文)**
```
ambient guqin folk, tang dynasty court instrumentation, xiao flute,
silk-string zither, stone chimes, sparse percussion, meditative,
wide natural reverb, male vocal, breathy and cold, minimal vibrato
```

**唱腔** 清冷男声,气声多、颤音少。第三部副歌后可加**无词吟哦**铺底。
**乐器** 古琴(主)· 箫 · 磬 · 编钟(极少)· 雨声与泉声作节奏底。
**[Intro 无词]** —— 京典模版规定 intro 不出歌词。

## 一条贯穿三部的格律(承平台既有京典签名)

每段 Verse 的**第五行**是一句**四四对仗的古语咒语**,与《声声慢》的
「苍天在上,孤魂何归」「呜呼哀哉,月照孤眠」同一格。三部的副歌第五句依次是:

**清风在上** → **明月在上** → **空山在上**

由风到月到空,三部一层比一层虚 —— 与分镜的「人间 → 独处 → 空」是同一条轴。

# 第二部 ·《竹里馆》

幽篁在上，此身无边

# 第三部 ·《鹿柴》

[Intro]

[Verse 1]
雾先来，山后到
先有白，再有轮廓
一条路走进林子就不见了
像一句话说到一半忽然停了
林深不语，径远无着

[Verse 2]
石阶半埋，苔已长满
柴门倒了一半，藤替它站着
门后其实什么也没有
只是林子的继续，和继续的林子
门无内外，径无来者

[Chorus 1]
空山不见人，但闻人语响
返景入深林，复照青苔上
你听见的都是真的
你看见的都在别处
空山在上，此身无相

[Verse 3]
声音从西边来，我就朝西边看
西边只有雾在慢慢地翻
鸟被惊起，证明那声音是真的
可鸟飞走之后，什么也没剩下
声有其实，形无其安

[Verse 4]
一块石头长得像坐着的人
我看了很久，它一直没有起身
后来我才明白过来
是我想要那里有人
心生万象，境自无痕

苔上有露，露里有整座林子
低下去看，苔就是森林
退开三步，森林又只是石上一小片绿
大和小，本来就没有商量过
一微一界，一念一尘

返景入深林，复照青苔上

光斜着进来，落在青苔上
苔绿了一瞬，又暗回去
林子恢复原状，像什么都没发生
只有远处，人语又响了一次
空山不老，长照无人

**Bridge 全部落在三幕开头**,这是三部一致的:
一部的 Bridge 是「人声第一次出现」,二部是「长啸」,三部是「尺度反转(苔即森林)」——
**都是那一部唯一一次"打破前面秩序"的地方**,分镜里对应的也正是那一幕的转折镜。
