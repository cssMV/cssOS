## 〇 · 为什么是王维(推荐理由 = 技术约束)

余额 7,962 credits 把我们锁死在 `seedance-1.5-pro`(3.5 cr/s)。
而 1.5-pro **唯一没被验证的能力恰好是「锁脸 + 多镜头人物一致」** —— Jing 看片时说过
「1.5-pro 只有大雁」,那句话就是答案:**它的好镜头全在山水,不在人脸。**

所以下一部必须选一个「主角是天地、不是脸」的题材。王维是这个约束下的最优解,
而且是**唯一一个约束反过来变成优势**的:

**三首诗的人物密度天然递减 —— 这不是我为了迁就引擎编的,这是原诗本来的走向。**

| 部 | 原诗 | 人 | 引擎风险 |
|---|---|---|---|
| 一 ·《空山新雨》 | 山居秋暝 | 浣女、渔舟 —— **有人烟,但都在远处、隔着竹与莲** | 低(全远景) |
| 二 ·《竹里馆》 | 竹里馆 | **只剩一个人**,独坐弹琴,「深林人不知」 | 中(单人剪影,不见脸) |
| 三 ·《鹿柴》 | 鹿柴 | **「空山不见人」—— 一个人都没有** | **零** |

**从人间 → 独处 → 空。** 引擎的短板在第三部彻底不存在,而第三部恰好是全曲的最高处。
选题和技术在这里是同一件事。

另:**32:9 就是手卷。** 王维是「诗中有画」、南宗山水之祖,《辋川图》本身就是横幅长卷。
不是把诗塞进画幅 —— 画幅本来就为它而生。所以本片的**招牌运动是「极缓横移」(展卷)**,
而不是《寻寻觅觅》的「极缓推」。这是两部片子在观感上必须区分开的地方。

**货架补位:** 李清照(凄)· 苏东坡(旷)· 杜甫(沉)· 唐伯虎(风流)· 李白(狂) ——
**独缺「静」**。王维补的是空位,不是重复。

## 一 · 视觉系统(三部通用,不变。这是"是同一部作品"的来源)

| 项 | 设定 |
|---|---|
| **色板** | 三色:**石青**(远山/暮天)· **苔绿**(林/苔/竹)· **月白**(水/雾/月/石)。**全片禁用暖橙与饱和红** —— 这是与《声声慢》的"陈金"色系刻意拉开的一条线 |
| **光** | 只有**自然光**:天光、月光、返景(斜阳穿林)。**全片禁用一切人造灯火**(《声声慢》是灯,辋川是天) |
| **镜头** | 长焦压缩(85–135mm 感)为主,**每幕允许一个真·大远景**(手卷全景)。禁广角畸变、禁无人机俯冲 |
| **运动** | 招牌是**极缓横移**(模拟展卷,自右向左或自左向右,每镜只走一个方向)。辅以**完全静止**。**极缓推每部限用 3 次**,留给情绪最高的镜。禁手持抖动 |
| **氛围** | 每镜必须有**一层介质**:雨、雾、水汽、竹影、光柱、飞尘。空气要看得见 |
| **构图** | 人物**永不超过画面 1/6 宽**(比《声声慢》的 1/3 更小),永远落在三分线外侧。**全片绝不出现脸部特写 —— 这是硬约束,不是风格选择** |
| **反复母题** | ①**水**(雨/泉/涟漪/舟痕)②**竹**(喧/影/节)③**月**(照/落/映)④**苔**(返景复照)⑤**空**(留白 ≥ 画面 1/2) |
| **声画分层** | 视频轨**永远静音**。音乐/歌词/情绪字幕三条线独立 —— 四轨分离铁律 |

### 锚定:**双锚**,不是单锚

《寻寻觅觅》靠一张人物定妆图锚全片。**本片不能这么做** —— 1.5-pro 锁脸不可靠,
而且我们本来就不拍脸。改成:

**锚 A ·「地貌锚」(三部全片引用,最重要)**
先用 `gpt-image-2` 出一张 21:9:

> 唐代辋川山谷,雨后初霁的黄昏。近景湿润的青石与苔痕,中景一片竹林与松,
> 远景层叠的青灰色山峦被雾切成三层。一线清泉自石上流下。
> 石青、苔绿、月白三色,无任何暖光。长焦压缩,天空占上三分之一,
> 画面右侧大量留白。中国青绿山水的质感,不要油画感,不要现代锐化。

**锚 B ·「人物锚」(只用于第一、二部;第三部禁止使用)**

> 唐代文士,青灰麻布圆领袍,幞头,身形清瘦。**背身或极侧身,面部完全不可见**,
> 独立于竹林边缘,占画面不超过六分之一宽,其余全部是林与雾。
> 自然天光,无人造光源。长焦浅景深。

> **第三部一张人物锚都不传。**「空山不见人」是字面意思 —— 传了就是废片。

## 三·五 · 样镜实测结论(2026-08-26 已跑完,花掉 114 credits)

**验了三镜 + 两张锚图,结论改变了两条拍摄方法。** 原始文件:

| 项 | 地址 |
|---|---|
| 锚 A · 地貌(**无人**,采用) | `artifacts/mv-plates/wangchuan/plateA-terrain-v2-7afd3a2c66221e14.png` |
| 锚 B · 人物(采用) | `artifacts/mv-plates/wangchuan/plateA-terrain-8902244088038121.png` |
| #3 大远景 | `artifacts/mv-shots/wangchuan/shot-ww03-d26407a1f0befa68.mp4` |
| #24 苔特写 | `artifacts/mv-shots/wangchuan/shot-ww24-f430a3335f7d1d1f.mp4` |
| #42a 地貌锚重生成 | `artifacts/mv-shots/wangchuan/shot-ww42a-d30da2635fef75ae.mp4` |
| #42b 末帧锚重生成 | `artifacts/mv-shots/wangchuan/shot-ww42b-de442e1c598bb5fe.mp4` |

### 结论一(最重要):**1.5-pro 守得住「世界」,守不住「这一个」**

`#24` 与 `#42a` 用**同一张锚图**生成,结果:同一块青灰石、同一种星状苔、同一质感、
同一色调 —— 但**换了一片苔**,还多出一株蕨。改用 `#24` 的**末帧**当锚(`#42b`),
不但没锁住,反而凭空长出鹅卵石和一个星芒炫光(现代数码味,破了全片的克制)。

**这和它锁不住脸是同一个能力缺口,只是换到了地貌上。** 也就是说:
**「同一片苔,同机位」这条呼应,这个引擎生成不出来。**

**→ 定案改法:`#42` 不重新生成,直接对 `#24` 那一条做后期布光。**
这样「同一片苔」不是求来的,是**物理上就是同一条片子**,一致性 100%,且零引擎成本。
已验证可行(`ww42c_graded.mp4`):

```bash
# 逐像素 alpha 的暖光楔(RGBA PNG, 边缘平滑归零 —— 用 RGB + 统一 aa 会露矩形硬边)
# 亮度/饱和/色温随 sin(PI*t/T) 起落 = 光到来 → 最盛 → 退去
ffmpeg -y -i <shot24>.mp4 -loop 1 -i beam2.png -filter_complex "\
[0:v]eq=brightness='0.09*sin(PI*t/7)':saturation='1+0.60*sin(PI*t/7)':\
     gamma_r='1+0.09*sin(PI*t/7)':gamma_b='1-0.07*sin(PI*t/7)'[base];\
[base][1:v]overlay=x='-1100+(W+1100)*(t/7)':y=0:eval=frame,format=yuv420p[out]" \
 -map "[out]" -t 7 -r 24 -c:v libx264 -crf 18 -an <shot42>.mp4
```

**一般化的原则:凡是要求「和某镜完全一致」的镜头,一律用后期从那一镜派生,
不要向引擎重新求一次。确定性的事交给 ffmpeg,不确定的才交给引擎。**

### 结论二:**引擎守不住色板,后期能守住**

`#3` 横移生效、无人、三层山雾都对,但它**跑回了「航拍风光大片」**:
暖森林绿压过了石青/苔绿/月白,雨丝没出现,运动带无人机味。
1.5-pro 对细致美学指令的服从度有限,会向"通用漂亮"回归。

**→ 定案:全片增加一道「色板收敛」后期,不再指望 prompt 守色。** 已验证:

```bash
ffmpeg -i <shot>.mp4 -vf "\
colorbalance=rs=-0.06:gs=0.02:bs=0.10:rm=-0.10:gm=-0.02:bm=0.09:rh=-0.05:gh=0:bh=0.06,\
eq=saturation=0.72:contrast=0.94:brightness=0.02:gamma_b=1.06,\
curves=all='0/0.06 0.5/0.5 1/0.96',format=yuv420p" -crf 18 -an <out>.mp4
```

暖绿被压掉、整体归到青灰、黑位抬起来做绢本灰、雾读成月白。**三部所有镜头统一过这一道。**

### 结论三:**美学基调改称「电影写实 + 冷色三色板」,不再写「绢本」**

「绢本/青绿山水」是我加的说法,**引擎做不到**,锚图也没吃到。而 Jing 对《寻寻觅觅》
定妆图的评价是「凄凉美,就要这种视觉效果」—— 那本来就是**写实电影感**。
统一到这一路,与平台既有真视频风格一致,也不必和引擎硬顶。

### 结论四:**镜头时长一律取 4 / 6 / 8 秒**

`#42a` 首次用 7 秒被拒:seedance 接受 7 秒,但**兜底链上的 veo 只接受 4/6/8**
(`Duration must be 4, 6 or 8 seconds`)。分镜表里的 5/7/9/10/11/12 秒都要重排到
4/6/8 的组合 —— **等音乐出来、按逐字对齐回填时一并处理**,不必现在改。

### 还没验、开拍前必须补的一项

**无人山谷的"无人"能不能在 55 镜里守住。** 锚图第一次就违反了 `no people`
(我写了它照样画人),靠改成正面表述(`UNINHABITED`/`EMPTY OF ALL LIFE`/逐项列举禁止物)
才拿到干净的一张。**第三部 55 镜每一镜都要自动查一遍有没有人影**,不能靠人眼抽查。

4. **逐镜生成**:`/api/admin/mv-shot`,`model=seedance-1.5-pro`,
