# 众筹拍电影 · 公开版文案 (W2070)

**用途:** 发平台 + 六社交。**只讲愿景、只收邮箱, 不收钱、不承诺回报。**

**与内部版 `crowdfunded-films.md` 的分界(重要):**

| 内部版有, 公开版**不能有** | 为什么 |
|---|---|
| 精确单价($0.0175/秒)、30% 余量、毛利 | 底牌, 发出去等于交给竞争者 |
| 证券法风险分析(Howey 四条) | 公开讨论自己的法律风险 = 给对手递刀 |
| 状态机 / 退款细则 / 律师问题清单 | 内部规格 |
| 「支持 $6.99」这类**要约措辞** | **律师过审前, 像在收钱就已经是公开募集** |

**公开版保留「五十个人拍一部长片」这个说法** —— 它是全部说服力所在, 而且
seedance 的价目本来就是公开的, 任何人都能自己算出量级。**给量级, 不给我们的账本。**

## 一 · 平台公告(长版, 发站内)

**标题:** 让五十个人拍出一部电影

拍一部 180 分钟的电影, 过去需要一支剧组、一年时间、一笔你我都拿不出的钱。

**现在它的算力成本, 已经掉到三位数。**

这不是比喻。我们刚拍完第七部三部曲 ——《Popol Wuj · 玛雅三部曲》, 162 个镜头,
870 秒成片, 从冥界的白骨之树到破晓的玉米田, 全部由 AI 生成。
**我们知道它花了多少, 精确到分。**

于是有了一个念头:

> **如果一部长片的成本掉到几百美元, 那它就不再需要一个投资人。它需要五十个观众。**

**我们要做的事**

一个人带着完整的剧本和几支预告片站出来说:「我要拍这部电影。」
其他人看了预告, 觉得值得一看, 就预先买下一张票。
**票买够了, 电影就开拍。** 拍的过程你能实时看见 —— 一个镜头一个镜头地生成出来,
就像看着底片显影。拍完了, 所有预先买票的人一起看。

没买够, 就不拍, 钱也从来不会离开你的账户。

**第一部会是《时间帝国》**

180 分钟以上。**多个结局** —— 这是传统电影做不到的:
一部电影拍三个结局, 在胶片时代等于拍三部电影;
在这里, 它只是多几个镜头。

**现在还不到买票的时候**

我们还在把规则和条款做扎实 —— 这种事一旦牵涉到别人的钱, 就必须先做对, 再做快。

**如果你想成为第一批参与的人, 留一个邮箱。**
开放那天, 你会第一个收到消息。

*(现阶段仅登记意向, 不收取任何费用, 不涉及任何投资或收益承诺。)*
