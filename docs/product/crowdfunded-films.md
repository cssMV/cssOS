# 众筹拍电影 · 方案 (W2068)

**Jing 2026-09-02 提出, 本文按「不设分红」定稿。**

> 用户以一张观影权的价格($6.99 / $9.99)参与众筹一部尚未拍摄的电影;
> 达标后开拍, 拍成后参与者免费观看。

---

## 零 · 一句话结论

**这个模式在别人的平台上不成立, 在我们这里成立 —— 因为一部 180 分钟的电影,
我们的制作成本约 $300, 五十个人就能拍出来。**

**但原方案里的「分红」必须去掉** —— 它会把 $6.99 从预购变成证券。详见第三节。

---

## 一 · 成本模型(用真实生产数据推导, 不是估计)

**基准: 《Popol Wuj · 玛雅三部曲》实测**

```
870 秒成片 = 3,045 credits = $15.22
→ 单价 3.5 credits/秒 ≈ $0.0175/秒   (seedance-1.5-pro)
```

**《时间帝国》180 分钟 = 10,800 秒:**

| 项目 | 用量 | credits | 美元 |
|---|---|---|---|
| 主线视频 | 10,800s × 3.5 | 37,800 | $189.00 |
| 多结局(3 结局各 +20 分钟) | 3,600s × 3.5 | 12,600 | $63.00 |
| 配乐(约 30 首 × 12) | — | 360 | $1.80 |
| 歌词 / 剧本 / 字幕(LLM) | — | ~800 | $4.00 |
| 封面 / 锚图 / 预告片 | — | ~1,200 | $6.00 |
| **合计** | | **~52,760** | **≈ $264** |
| 留 30% 余量(重拍/复验/失败重试) | | | **≈ $345** |

**结论: 一部 180 分钟三结局长片, 全成本约 $300–350。**

| 定价 | 回本人数 |
|---|---|
| $6.99 单结局 | **50 人** |
| $9.99 多结局 | **35 人** |

**对照: 传统众筹拍长片需要几十万美元、数千支持者。差三个数量级。**

### 预告片几乎免费 —— 这是发起人门槛能设高的前提

一支 60 秒预告 = 210 credits ≈ **$1**。发起人做三支预告只花 $3。
**传统制片人做不到, 所以他们的众筹页只能放 PPT; 我们的可以放真片。**

### 成本透明是我们独有的说服力

我们能把「这部片需要 52,760 credits, 你出的 $6.99 覆盖其中 0.7%」写在页面上。
**没有别的平台知道自己的边际成本到这个精度, 所以没有别人敢这么写。**

## 二 · 三条只有我们有的结构性优势

1. **「流流流」= 天然的进度直播** —— 支持者能实时看着自己出钱的镜头一格格生成。
   传统众筹只能发月报。这是花钱买不到的参与感, 而且我们已经有了。
2. **多结局是既有能力** —— 多画面胶囊本来就是平台定义的一部分, 不用新造。
   而多结局正好为 $9.99 档提供了**不需要解释的**溢价理由。
3. **成本随长度线性且可预先算准** —— 传统电影的预算会失控, 我们的不会。
   **可以对支持者承诺"不追加预算"**, 这在传统众筹里是不可能的承诺。

## 三 · ⛔ 为什么必须去掉「分红」

**一旦承诺分红, $6.99 就不是预购, 是投资合同。** 美国 Howey 判准四条全中即为证券:

| Howey | 原方案 |
|---|---|
| 投入金钱 | ✅ $6.99 |
| 投入共同事业 | ✅ 同一部电影 |
| 期待获利 | ✅ 明说了分红 |
| 获利来自他人努力 | ✅ 平台与发起人拍片 |

**向公众销售未注册证券是联邦层面的违法。**

有一条合法路径叫 **Reg CF(众筹豁免)**: 一年可募约 $500 万, 但必须通过持牌众筹门户、
提交 Form C、提供经审计财务。**这套合规成本对一部 $300 的电影是荒谬的 —— 比电影本身贵一百倍。**

### 定稿: 纯预购 + 非现金回报

**$6.99 / $9.99 = 预先购买一张观影权。不承诺任何金钱回报。**
这就是 Kickstarter 跑了十几年的实物回报模式, 合法且成熟。

参与感用**不是钱**的东西给:

| 回报 | 为什么这个不是证券 |
|---|---|
| 片尾署名 Founding Backer | 荣誉 |
| 平台 credits 返还 | 平台内货币, 只能在站内消费 |
| **拥有那一版胶囊** | 多画面胶囊的原有定义 —— 支持者拥有「他们那一版」 |
| 续集结局的**投票权** | 治理权, 不是收益权 |
| 抢先看 / 幕后 / 未采用镜头 | 内容回报 |
| 终身免费看该发起人的下一部 | 未来兑换权 |

**若将来一定要给钱, 唯一相对安全的形式是给【有创作贡献的人】分收益**
(写剧本 / 定结局 / 配音) —— 那是**报酬**不是投资回报。这条同样要律师先看。

> ⚠️ **本节是分析, 不是法律意见。上线前必须由懂美国证券法的律师过一遍。**
> 几百美元咨询费, 比事后便宜一万倍。

## 四 · 发起人门槛

**必须先花过钱, 才能募别人的钱。**

| 要求 | 为什么 |
|---|---|
| 完整剧本 | 没剧本的都是空想 |
| **≥2 支预告片, 且必须在本平台生成** | **筛掉 90% 空手套** —— 他自己先花了钱 |
| 平台人工审核后才公开 | 第一个骗局会毁掉整个模式的信任 |
| 发起人身份可查 + 站内既往作品 | 可追责 |

**发起人必须公示:**

```
完整剧本 · 预计时长 · 结局数量与分支结构图 · ≥2 支预告片
【成本明细】需要多少 credits / 折合多少钱 —— 由平台自动算好, 不许发起人自填
【目标金额与截止日】达标才扣款, 不达标全额退回
【交付日期】以及超期未交付的处理办法
```

## 六 · 状态机

```
draft 草稿
  └→ in_review 待审核        发起人提交
       ├→ rejected 未通过     可修改后重投
       └→ funding 募集中      审核通过, 公开
            ├→ funded 已达标       达标且到截止日 → 扣款
            │    └→ producing 拍摄中   进度直播开启
            │         ├→ delivered 已交付  支持者获得观影权 + 回报
            │         └→ overdue 逾期      触发第七节的逾期条款
            └→ failed 未达标       到截止日未达标 → 全额退回, 不扣款
```

**关键: 扣款发生在 `funding → funded` 那一刻, 不是支持的那一刻。**
在此之前只做支付授权(authorization), 不做扣款(capture) —— Stripe 原生支持。

---

## 七 · 退款规则

| 情形 | 处理 |
|---|---|
| **未达标** | **不扣款**(从未 capture), 授权自动过期。零手续费损失。 |
| 达标前支持者主动取消 | 撤销授权, 无条件 |
| 达标后、开拍前取消 | 全额退款(平台承担支付手续费) |
| **开拍后取消** | **不退** —— 钱已变成 credits 烧掉了。页面必须在支持前明确告知 |
| 逾期未交付(超交付日 30 天) | 支持者可选: 继续等 / 全额退(由平台垫付) |
| 项目被平台下架(违规) | 全额退, 平台承担 |
| 成片交付但支持者不满意 | **不退** —— 这是创作, 不是商品瑕疵。页面明示 |

**平台必须自己垫得起逾期退款** —— 否则一个发起人跑路就会把平台拖下水。
建议: 达标金额的 20% 由平台暂扣至交付后释放。

## 八 · 分阶段落地

| 阶段 | 做什么 | 法律风险 |
|---|---|---|
| **零** | **Jing 自己发起第一个**(《时间帝国》), 既是发起人也是平台 | **零** —— 自己募自己 |
| 一 | 开放给受邀的少数创作者, 仍是纯预购 | 低 |
| 二 | 拿到律师意见后再决定要不要碰收益分享 | 需前置合规 |
| 三 | 全面开放 + 发起人分成 | 需完整合规 |

**第零阶段现在就能做, 零法律风险, 而且能立刻验证最关键的那个假设:**
**会不会有五十个人, 愿意为一部还没拍的电影, 各付 $6.99。**

## 九 · 给律师的问题清单

1. 纯预购(交付观影权、无金钱回报)在美国是否构成证券? 需要哪些免责声明?
2. 「平台 credits 返还」是否会被认定为金钱等价物, 从而触发证券认定?
3. 「拥有那一版胶囊」若将来可转售, 是否改变性质?
4. 达标前只授权不扣款, 在各州的预售法规下是否需要额外披露?
5. 逾期未交付时, 平台对支持者负什么责任? 需不需要托管账户(escrow)?
6. 未来若给「有创作贡献者」分收益, 应按雇佣、承揽还是版税结构?
7. 跨境支持者(欧盟 / 英国 / 中国)分别适用什么规则?
8. 需要在条款中写明的最低披露集合是什么?
9. 平台作为收款方与作为居间方, 责任差异有多大? 是否应改由发起人直接收款?
10. Reg CF 的门槛在什么规模下才划算 —— 我们将来做到多大要转过去?
