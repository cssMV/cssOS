# 《时间帝国》圣经 v2 —— 史诗重构

2026-08-12。**这份文件取代 v1 的规模与人物设定，保留 v1 的机制。**
v1（`timeempire-voyager-archive.md`）不删，作为机制来源继续有效；本文与它冲突的地方，
**以本文为准**。

## 零 · 为什么要重构（这一节是给我自己看的）

不是审美分歧。是我写岔了，而且可以核对。

`public/timeempire-intro.html` 是**已经上线、已经对外发布**的设定：

| 已发布设定 | v1 剧本写成了 |
|---|---|
| xÈth 从南方一个**伪造的出生**开始，爬过政坛，**进入这个国家的最高职位** | 一间改造过的旧邮局里的中层公务员 |
| **他要把一个共和国加冕为帝国，宣布新纪元元年** | 他要统一伤亡数字 |
| Ethan 是他的**老同学**，**半人半火星**，一个选了我们这边的不朽者的儿子 | 一个跟他毫无关系的普通人类档案员 |
| Clara **发誓不惜代价守住时间线** | 男主的女友 |
| **一个世纪以来**，不朽的火星人编辑我们的**战争与选举** | 几周之内的一个部门项目 |
| 一位小说家把警告写进一本著名的书，**被归档为虚构** | 不存在 |
| **Twin-Star War：地球对火星** | 火星是一句台词 |
| 「有些帝国建在土地上。**这一个建在时间上。**」 | 片名没有对应物 |

**结论：v1 不是一部小一号的《时间帝国》，它是另一部电影。**

而这个错的根源可以指名道姓：我在莫比乌斯评估里写过
「这部片之所以能用四块四拍出来，正是因为它不需要时空隧道」——
我把**一个预算约束的优点，写成了这部片的优点**。约束一撤，那句话就是错的。

## 一 · 留下什么 / 推倒什么

### 留下（机制层 —— 这是 v1 真正值钱的部分）

这些**不是**室内剧的产物，它们是这部片区别于其他一千部外星入侵片的全部原因。
其中大部分在史诗规模下**更好用**，不是更差用。

| v1 条目 | 为什么在史诗版里更强 |
|---|---|
| **§2.1 编辑，而非穿越** | 这正是「他的编辑写进了我们的战争、我们的选举」的引擎。一个能改选举结果的人，比一个能穿越的人可怕得多。 |
| **§2.3 三样不可改写的东西**（已离场的光 / 模拟形状 / 亲历经验） | 面对一个**掌握了整个政府全部记录**的总统，这三样是仅剩的武器。在室内剧里它是聪明设定；在史诗里它是全片的军械库。 |
| **§2.4 铀-238 钟 + 旅行者一号** | 一个统治了记录的人，唯一诚实的证人在太阳系外面，而且带着一台他改不了半衰期的钟。 |
| **§2.5 火星只是上一站** | 直接变成 Twin-Star War 的主视觉含义（见 §三·场面 2）。 |
| **§2.6 莫比乌斯是他的信仰** | 一个要宣布「新纪元元年」的人，必须有一套宇宙论。 |
| **§6.1 所有结局最后四秒逐帧相同** | 结局从 2 个涨到 5 个，这条只会更狠。 |
| 费米登记表 40,921 | 变成画面（见 §三·场面 4）。 |
| 1977 洁净室 / 金唱片 | 变成**前史的一半**（见下）。 |
| Margot 被改写 | 保留为一场戏，但降级：它现在是无数次编辑里最小的一次，用来教观众规则。 |

**新的统一线索（把已发布设定和 v1 机制焊在一起）：**

> **二十世纪留下了两样东西：一本被归档为虚构的书，和一张飞出太阳系的唱片。
> 那本书他改得掉。那张唱片他改不掉。**

### 推倒（规模与身份层）

- xÈth 的职位、来历、时间跨度 —— 全部按已发布设定重写
- Ethan 的血统与他跟 xÈth 的关系 —— 老同学 + 半人半火星，这改变他每一场戏
- Clara 的动机 —— 从「爱人」改成「立过誓的人」，她跟 Ethan 会真的对立
- 六个 beat 的图 —— 那是电视剧的形状，史诗要三部结构
- 时间跨度 —— 从几周改成**数年**（"across years of wits and shadows"）+ 一个世纪前史

## 二 · 新人物设定（按已发布设定）

### xÈth —— 使节 · 总统

不朽。温和。危险。名字带一个下沉的重音 `è` —— 人类的舌头拿不住的、古老的恶的音。

**从南方一个伪造的出生开始，爬过政坛，进入最高职位。** 他不是政变上台的，
他是**被选上去的** —— 而且选举是干净的，因为他没有必要作弊：他修改的是
选民在投票前**记得的东西**。

他要做的事，用他自己的话说不是篡位，是**收尾**。加冕一个共和国，
宣布元年，然后所有痛苦结束。

**铁律（承 v1）：他必须堂堂正正赢下一场戏，而且观众得站在他那边。**
一个反派总统很容易写成漫画。他不是。

### Ethan Vance —— 时间观测者 · 半人半火星

xÈth 的**老同学**。父亲是一个**选了我们这边的不朽者**。

于是：他能感知时间被改写过（火星血），但他会死（人类血）。
他跟 xÈth 认识四十年，两人都知道对方是什么。

**这条血统改变了每一场戏**：他不是一个发现了阴谋的小人物，
他是唯一一个**从内部知道规则、却选择了输的那一边**的人。

### Clara Sinclair —— 立过誓的人

**发誓不惜代价守住时间线。** 「不惜代价」在第三幕必须兑现，
而且代价必须是 Ethan。

v1 里她是女友。v2 里她跟 Ethan 会在第二部末尾**真的对立**，
因为守住时间线和救 Ethan 是两件不能同时做的事。

### 那位小说家（新增，已发布设定要求）

一个世纪前撞破了秘密，写成一本著名的书，警告世人。**警告被归档为虚构。**

他本人后来怎么了，电影只给一行档案。但那本书在全片出现三次，
每次都在书架上、每次都没人当真 —— **这是全片最好的一个反复出现的笑话，
而且它一点也不好笑。**

### June Hale

保留。她现在是白宫里的人，不是邮局里的人。她仍然留在 xÈth 身边到最后。

## 三 · 史诗层：六个大场面，全部从「编辑」这个机制里长出来

**这是 v1 完全没有的一层。** 关键要求：不外挂太空战。每一个大场面
都必须是「他们编辑而不是摧毁」这条规则的直接后果 —— 否则就是别人的电影。

### 场面 1 · 被删掉的那场战争

首次接触发生过。抵抗发生过。**整场战争被打完了，然后被编辑掉了。**

Ethan 找到一卷幸存的胶片 —— 因为**模拟形状不可改写**（§2.3）。

于是观众得到一场真正的、大规模的、惨烈的战争戏……
**然后在同一部电影里，它从我们手里被拿走。**

我们既拍了那场仗，又让那场仗成为全片最恐怖的一件事。这是史诗场面，而且它有意义。

### 场面 2 · 火星是一具尸体，而且它很安详

**Twin-Star War 那张主视觉的真正含义。**

火星上没有陨石坑，没有废墟，没有战争痕迹 —— 因为**他们不摧毁，他们编辑**。
一颗红色的、平静的、彻底空的星球，一颗**什么坏事都没发生过的**星球，
因为所有发生过的事都被移除了。

**红星球就是蓝星球的未来。** 这一张图必须在前十五分钟出现。

### 场面 3 · 一个体育场那么大的办公室

火星人没有舰队。他们有**一套文官系统**。

揭示镜头：一万个他，一模一样的仪态，彬彬有礼，正在办公。
桌子排到看不见尽头。

观众在那一秒明白：**这不是入侵，这是行政机关，而且早已满编。**

（这是本片能给出的、唯一不违背设定的「舰队登场」镜头，而且比舰队可怕。）

### 场面 4 · 四万零九百二十一

登记表变成画面。四万零九百二十一个世界，一个接一个，每个都有最后一次发射。

按 §2.5 的双重读法 —— 这既可能是宇宙的墓地，
**也可能是他的履历**。电影永远不说是哪一种。

### 场面 5 · 加冕，以及元年一月一日

共和国变成帝国**不是政变，是一次修订**。

同一个大厅、同一批人、同一场典礼，**被重放三次**。每一次文件上的字不一样，
而所有人的表情都一样自然、一样确信这就是本来的样子。

第三次的时候，日期是**元年**。

### 场面 6 · 全球第三幕

要让地球的记录不可编辑，它必须**离开**，而且必须**同时从所有地方离开** ——
因为一座天线可以被更正，十几座同时的不行。

第三幕是全球的：十几个国家的射电望远镜，被普通人占住、守住，
对着同一个九十分钟的窗口。

史诗、有钟、有牺牲 —— 而且每一个地点仍然只是**一个有人的房间**，
我们的管线拍得了。

## 四 · 结构：三部 · 195 分钟

| | 内容 | 分钟 |
|---|---|---|
| **序章** | 二十世纪的两件遗物：一本被归档为虚构的书，一张飞出太阳系的唱片。1977 洁净室。**火星，安详的尸体。** | 16 |
| **第一部 · 被归档为虚构** | 近未来美国。xÈth 就职。Ethan 感觉到地面在动。Margot 被改写（教规则）。老同学第一次同框。**被删掉的那场战争。** | 62 |
| **第二部 · 行政机关**（分线，观众看一条） | `earth` 线：Ethan + Clara 建案，发现记录内部无法取胜 / `mars` 线：June 在白宫内部，看见那套系统真的在减轻痛苦。**体育场办公室。四万零九百二十一。** 末尾 Clara 与 Ethan 对立。 | 52 |
| **第三部 · 加冕与窗口** | 加冕（三次重放，元年）。全球第三幕。九十分钟窗口。 | 48 |
| **结局**（五选一） | 见下 | 13 |
| **coda** | 旅行者一号。**最后四秒，五个结局逐帧相同。** | 4 |
| | **单次观看** | **195** |

**为什么现在我认为 195 立得住，而上一版我认为 125 立得住 ——
因为上一版的材料里没有前四样东西。** 一部电影的时长不是态度问题，
是承重问题：一个世纪的前史 + 一场被删掉的战争 + 一次加冕 + 一颗死掉的行星 +
两个四十年的老同学，这些东西每一样都要时间才能压得住。

**上限 210 分钟。** 超过就不是史诗了，是耐力测试。

## 五 · 五个结局

已发布设定只锁死了两个（"In one, time is saved. In another, the Empire of Time begins."），
并说这是**一组**结局。以下三个是提案。

| # | 结局 | 内核 |
|---|---|---|
| 1 | **时间被守住** | 光离场，未经编辑。他第一次面对一件他改不了的事。（已发布） |
| 2 | **时间帝国建立** | 加冕完成，元年开始，所有痛苦结束。**而且它看起来是好的。**（已发布） |
| 3 | **双输 · 第 40,922 行** | 广播发出去了，但离场的**已经是被编辑过的版本**。地球成为登记表上新的一行。**这是费米结局，也是五个里最重的一个。** |
| 4 | **他签下自己的名字** | 一百多年来第一次，他让一件关于**他自己**的真事留下。于是他终于可以被反驳 —— 也终于可以被审判。唯一一个有人改变的结局。 |
| 5 | **莫比乌斯** | 人类赢。最后一秒揭示：赢的人正在成为下一届行政机关。游戏的形状，只在最后一秒变成字面意思。 |

**§6.1 在五个结局上全部成立：最后四秒是同一份素材，逐帧相同。**
观众走完第二条、第三条路，会发现结尾那个镜头一帧没变 —— 五遍之后，
那四秒就不再是一个镜头，而是这部片的论点。

## 六 · 规模与成本（对照室内剧版）

| | v1 室内剧 | **v2 史诗** |
|---|---|---|
| 单次观看 | 125 min | **195 min** |
| 总独有素材 | 180 min | **约 320 min** |
| 镜头（ASL 6s，史诗动作段更碎） | 1,543 | **约 3,200** |
| 生成单元 | 2,160 | **约 4,500** |
| 重出倍数（难镜占比从 15% 升到 25%：行星 / 群戏 / 战争 / 时代 / 加冕） | 2.44× | **2.96×** |
| 总生成次数 | 7,600 | **约 19,200** |
| **1080p 成本** | $2,900 | **约 $7,400** |

**钱仍然不是瓶颈。** 2.5 倍的规模换来的是一部真的对得起首页那张图的片子。

真正的瓶颈没变，而且变重了：**那个「Ah」，以及 3,200 个镜头的身份一致性。**
