## `b_open-animatic.mp4` — 2:50 · 1470×630 · 24fps（历史版本）

**这是动画分镜，不是成片。** 静帧定格 + 一个运动镜 + 心跳 + 烧录字幕。
零新增生成 —— 全部用 `../timeempire-plates/b_open-coldopen/` 已有的素材拼的。

### 它要验的是什么

到剪之前，**没有任何证据证明这些镜头连起来是成立的**。单张都对，但节奏对不对、
剪在一起有没有戏、Margot 那一下到底吓不吓人 —— 全都没验过。

**一部片子的第一次真相时刻，是第一次连着看。**

### 刻意的做法

- **静帧一律定格，不加缓推**。这部片的镜头本来就是不动的（铁律 4）——
  给动画分镜加 Ken Burns 会让人误判成片的节奏。
- **心跳只在开头 24 秒**，第 18 秒起淡出。全片只许三次，这是第一次。
- 字幕是**烧录的临时件**，只为读懂 —— 成片走配音，不留字幕。

### 已知的不成立处

- 无人声。2372 行剧本一句没配。
- 第 17 段（「She was sure.」）复用了第 13 段的画面 —— 缺一个「Margot 走后
  Ethan 独自站着」的镜头，补拍时要加。
- 洁净室那场用 `2A` 出现了两次（分别配两句台词），成片需要更多机位。
