## 一 · 不变量（最高优先级）

### `INVARIANT-artifact-voyager.png`

**这是全片唯一一件在两个结局里必须完全相同的东西。**

它要出现在四处，且**全部必须由这一张派生**：

| 出处 | 用法 |
|---|---|
| `b_open` §6 | 墙上投影的那一帧 |
| `b_mars_infiltrate` §3 | xÈth 房间墙上的挂画（暗淡蓝点那张另算） |
| `coda` | 博物馆展柜里的实物 |
| `coda` 最后四秒 | 星空中的那一帧 |

**铁律：最后四秒不许重新生成。** 一份渲染文件、一个 sha256，剪进两条尾巴。
上线前校验两支成片末 4 秒逐帧哈希相同（圣经禁令 9）。

### `INVARIANT-final4.png` / `INVARIANT-final4.mp4` — 最后四秒，已锁死

**这是全片的锚点。已经渲好了，不要再生成第二次。**

| | |
|---|---|
| 静帧 sha256 | `350e4c2af80171767a1182729f309e0dcfae8827254a276d86929d9a3be5975e` |
| 成片 sha256 | `653a1f399ef2345bda29004f4ad72ba342054b6d644a3943b3e4342b69a43353` |
| 规格 | 1470×630 · 24fps · 96 帧 · **4.000000 秒** · 无音轨 |

由 `INVARIANT-artifact-voyager.png` 作参考图派生，构图照 `coda.md`：
**小、偏左下之外的偏置、大片空**，左上一颗略亮的星（「太阳是其中一颗，
且不被指认」）。三张候选里选的第三张 —— 另两张都太大太居中，有纪念碑感，
而这个镜头的意思恰恰是「它在走，仅此而已」。

**为什么不是 AI 生成的视频**：铁律 4 —— 引擎受不了「什么都不发生」，一定会
自己推镜。这个镜头的全部意义是它不动。所以做法是**静帧 + ffmpeg 定格**，
确定性、可复现。

**为什么是无损编码（`-qp 0`）**：第一版用 crf 16 出，96 帧解出来有 **12 个
不同的帧哈希** —— 有损压缩让一张静止图在解码后仍在微微「呼吸」。对一个全部
意义就是「不动」的镜头，这不能留。改无损后 96 帧 → **1 个唯一哈希**，
而文件只有 305 KB（每个 P 帧残差为零，压缩器无事可做）。

**复现命令**（改动前先想清楚，改了哈希就变了）：

```
ffmpeg -loop 1 -i INVARIANT-final4.png -vf "scale=1470:-1,crop=1470:630" \
  -r 24 -frames:v 96 -c:v libx264 -qp 0 -preset veryslow -tune stillimage \
  -pix_fmt yuv420p -an INVARIANT-final4.mp4
```

**尚缺**：心跳音轨（母题 3/3）。音频到位后与本片段合成，合成后**重新记录
sha256 并更新本节**。在那之前，本 mp4 是画面权威。

**1470×630 是故意的** —— 与 seedance 出片同尺寸，终剪时不产生任何缩放差异。

形制要点（提示词按**形状**写，不写型号名 —— 铁律 2）：白色抛物面大天线盘为
画面最大元素；三根支杆撑起副反射器；盘后下方是金箔包裹的**十边形**舱体；
一侧一根极长细杆，另一侧短杆挂三只圆柱罐；舱体侧面一块**小而哑光**的金色
圆盘。显式否定：`NO cylindrical body, NO barrel, NO boiler, NO capsule,
NO rocket, NO wings, NO solar panels, NO glowing parts`。

*（一次生成三张里选的第一张。另两张：一张把「斑驳」错加到了盘面上像月面，
一张太正面太平。）*

## 三 · 主参考脸

`face-ethan.png` / `face-clara.png` / `face-xeth.png`

**原创合成脸，不像任何真实在世或历史人物**（圣经 §10.5 铁律 5 红线 ——
xÈth 是总统角色）。

每张带一个可客观核对的标记，用来验收「是不是同一个人」：

- **Ethan** — 左眉一道细竖疤
- **Clara** — 右眼下一颗小痣
- **xÈth** — 淡琥珀色瞳、无皱纹

用法：每个含该角色的镜头，把对应 PNG 作 `image_urls` 条件传给
`google/nano-banana`；多人同框传多张。已实测通过（跨场景、三人同框、
六秒运动三项）。

**每次都要连服装一起写死** —— Ethan 旧毛衣 / Clara 皱大衣 / xÈth 炭灰西装。
不写就会变成战术背心和动力甲（铁律 6）。
