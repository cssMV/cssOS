# EMPIRE OF TIME — 参考图基准板

生成于 2026-08-10，引擎 `google/nano-banana`（KIE）。
配套：`../timeempire-voyager-archive.md` §10.5 制作铁律。

> **为什么这些 PNG 进了 git 仓库。**
> 生成它们的 `tempfile.aiquickdraw.com` 地址 **24 小时过期**。而参考图的全部
> 意义是「每次生成都拿同一张作条件」—— 一旦丢失，重新生成得到的是**另一张
> 脸、另一间屋子、另一艘探测器**，前面所有已生成的镜头就对不上了。
> 这不是素材，是**基准**。基准必须可复现，所以必须落库。
>

> 并在此登记 URL 与 sha256。现在只在 git 里，够安全但不够正式。

## 一 · 不变量（最高优先级）

### `INVARIANT-artifact-voyager.png`

**这是全片唯一一件在两个结局里必须完全相同的东西。**

它要出现在四处，且**全部必须由这一张派生**：

| 出处 | 用法 |
|---|---|
| `b_open` §6 | 墙上投影的那一帧 |
| `b_mars_infiltrate` §3 | xÈth 房间墙上的挂画（暗淡蓝点那张另算） |
| `coda` | 博物馆展柜里的实物 |
| `coda` 最后四秒 | 星空中的那一帧 |

**铁律：最后四秒不许重新生成。** 一份渲染文件、一个 sha256，剪进两条尾巴。
上线前校验两支成片末 4 秒逐帧哈希相同（圣经禁令 9）。

形制要点（提示词按**形状**写，不写型号名 —— 铁律 2）：白色抛物面大天线盘为
画面最大元素；三根支杆撑起副反射器；盘后下方是金箔包裹的**十边形**舱体；
一侧一根极长细杆，另一侧短杆挂三只圆柱罐；舱体侧面一块**小而哑光**的金色
圆盘。显式否定：`NO cylindrical body, NO barrel, NO boiler, NO capsule,
NO rocket, NO wings, NO solar panels, NO glowing parts`。

*（一次生成三张里选的第一张。另两张：一张把「斑驳」错加到了盘面上像月面，
一张太正面太平。）*

### `scene-cleanroom-1977.png` 待修三处

1. **唱片是竖立在方架里的，剧本写的是平放在打开的铝制封套里。** 竖着像博物馆
   陈列，不像装配台。
2. **所有人戴了口罩。** 剧本没写口罩，而且戴上就看不见脸 —— `b_open` 冷开场
   埋 xÈth 的那一笔会**直接失效**（识别点是脸，不是头发，见 b_open §1 连续性
   注记）。**必须去掉口罩。**
3. **机位是正面全景，没有给门口留位置。** `b_open` 需要后排门边站得下一个人，
   `b_mars_infiltrate` §3 还要从门口机位再走一遍同一场戏。**需要一张把门包进去
   的构图。**

## 三 · 主参考脸

`face-ethan.png` / `face-clara.png` / `face-xeth.png`

**原创合成脸，不像任何真实在世或历史人物**（圣经 §10.5 铁律 5 红线 ——
xÈth 是总统角色）。

每张带一个可客观核对的标记，用来验收「是不是同一个人」：

- **Ethan** — 左眉一道细竖疤
- **Clara** — 右眼下一颗小痣
- **xÈth** — 淡琥珀色瞳、无皱纹

用法：每个含该角色的镜头，把对应 PNG 作 `image_urls` 条件传给
`google/nano-banana`；多人同框传多张。已实测通过（跨场景、三人同框、
六秒运动三项）。

**每次都要连服装一起写死** —— Ethan 旧毛衣 / Clara 皱大衣 / xÈth 炭灰西装。
不写就会变成战术背心和动力甲（铁律 6）。
