## 拍之前先定的一件事：不跟身份漂移较劲

`b_converge` 是全片唯一需要**四张脸同框**的戏（Ethan / Clara / xÈth / June），
而铁律 7.7 已经说清楚：**脸的保真度随场景复杂度下降**。四个人挤在一间小机房里，
必然是全片最差的情况。

**所以按调度绕开，不硬扛：**

| 用途 | 镜头 | 做法 |
|---|---|---|
| 交代地理关系 | `C6-1` 四人同框 | 四个人都**很小**，房间是主体 —— 脸不承担识别，漂移无所谓 |
| 立身份 | `C1-3` `C2-1` `C4-2` `C5-1` `C3-1` | 各自的近景 / 双人，景别收紧，脸分到足够权重 |

**把限制当调度条件用，而不是当敌人。** 这一条建议写进圣经作为铁律 7.7 的
配套做法。

## `C6-2` —— 全片的分叉，而它必须看起来什么也没发生

这一格是整部电影的枢轴（观察者的注意力在此决定结局），而剧本与圣经都要求：
**不生成运动，用定格 + 极轻的呼吸。**

原因见铁律 7.5 的反面 —— 这里的戏眼**不是变化，是「尚未发生」**。
一旦让它动起来，观众就知道「此处有事」，而这四秒的全部要求是观众
**第一遍不该察觉任何事发生过**。

所以它是静帧，且是本 beat 唯一一处明确规定不许动的镜头。
