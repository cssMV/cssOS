## `M3-3` —— 同一场戏，换一个机位

这是全片重看结构的机关，也是这一 beat 存在的理由。

用的是**同一张洁净室基准板**（`../scene-cleanroom-1977.png`）—— 同一面墙、
同一张工作台、同样四个戴帽的人、同一张平放的金唱片 —— 只把相机搬进**门口**，
门框在前景垂直切下来。

于是观众第二遍看到的，是**同一个瞬间，从 xÈth 站的那个位置看过去**。

## `M3-4` —— 返工一次，而返工暴露了我自己的错

v1 我在提示词里写了「戴白纸帽，和别人一样」。**这跟 `b_open` 已经定下的
canon 冲突** —— 那边埋伏笔时明确保留了「他是全场唯一没戴纸帽的人」，理由是
「他不是来干活的，所以没换装」，而那正是重看时的识别点。

v2 改回**光头、银发全露**，靠在门边墙上、抱着手臂，刚笑完那一下，眼角还皱着；
四个戴帽的人在六米外虚焦。

**那个笑是暖的。** 他不是在冷笑 —— 他是真觉得好笑。这才是那句
「因为总有人会来把它拿掉」被满屋子人归档成玩笑的原因。

## `M3-2` —— 挂画必须是不变量本身，所以用合成

v1 生成失败：我的脚本没能把本地 PNG 当参考图传进去，退化成纯文字描述，
引擎画了一幅普通的暗调油画。

而这一格**恰恰不能靠生成** —— 画框里必须是 `../INVARIANT-pale-blue-dot.png`
本身（§6.1 逻辑：不变量在哪儿出现都得是同一份素材）。

做法：ffmpeg 把不变量裁一块竖幅（含光带与那个点）、压暗以匹配屋里照度、
贴进画框内区 `(440,415)–(590,588)`。确定性、可复现。

**一个意外的正确效果**：从屋子这头看过去，画框里**只剩那道光带，地球根本
看不见**。要走到跟前才有那个点。xÈth 的圣像，隔着房间看是一片光；
那颗地球不在里面。

## `M4-1` —— 费米寂静，一张表说完

剧本铁律：**不许任何角色讲授大过滤器**。所以意思必须由这张表自己说出来。

两列日期：`FIRST HEARD` / `LAST HEARD`。**每一行都有第二个日期 ——
只有最后一行没有：**

```
SOL   19 07 34 +15 41 02     -49      —      technological
ENTRIES 1–18 OF 40 921
```

四万零九百二十一个，全都停了。只剩我们还在响，而且才响了 49 个单位。

观众自己会数。等 June 说出「有东西在杀他们」、xÈth 答「不。他们做完了」，
那张表其实已经把话说完了。
