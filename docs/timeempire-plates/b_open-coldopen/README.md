**`1C` 为什么会错 —— 一条新教训：**

我把 `1A` 当参考图传进去并写了「keep her exact same face」。没用。
**因为她在 `1A` 里太小了。** 参考条件锁的是参考图里*显著*的东西，而她在
那张宽景里只占几十个像素 —— 引擎拿不到足够的脸部信息，于是另画了一个人。

**规矩：任何需要跨镜头保持长相的角色，都必须先有一张自己的中性棚拍脸板**
（跟 `face-ethan` / `face-clara` / `face-xeth` 一样），不能指望从场景宽景里
派生。这个女人虽然全片不具名、只出现在冷开场，但她在 `1A` 和 `1C` 里必须
是同一个人 —— **所以她也需要一张脸板。**

## `2A` — 三版，和一个被推翻的诊断

| 版本 | 结果 | 归档 |
|---|---|---|
| v1 | 🔴 失败 | `rejected/2A-v1-FAILED.png` |
| v2 | ⚠ 好转但仍孤立 | `rejected/2A-v2-better.png` |
| **v3** | ✅ **采用** | `2A-plant-wide.png` |

**v1 失败**：写了六条否定（`NOT the subject`、`NOT lit`、`NOT emphasised`…），
一条都没生效。他站在左墙边、独自一人、周围一圈空地、全画面最清晰 ——
与剧本要求（第一遍不该被注意到）恰好相反。

**我当时的诊断是「引擎做不到不起眼，只能改走合成」。这个诊断错了一半。**

**v2/v3 改了语法，不是改了管线**：一个否定词都不用，只描述**物理事实** ——
门框横切过他 / 前景那位的肩膀挡在他前面 / 相机对焦在工作台所以他是软的 /
他在门口离桌子还有六米。v3 一次成功，**合成没有做，也不需要做。**

详见圣经 §10.5 铁律 7（已按此重写）。

### v3 采用理由

- 他在门口深处，**最近那位戴帽者的肩膀正好切过他**
- 小、不亮、不居中；第一眼会被五顶纸帽和台上那张金唱片带走
- 重看时识别点是那头银发 —— 他是**全场唯一没戴纸帽的人**

最后这条本来是我担心的瑕疵（会让他扎眼），但反过来读恰好是角色本身：
**他不是来干活的，所以没换装。** 保留。
