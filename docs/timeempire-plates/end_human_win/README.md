|---|---|---|
| `H1-1-box-empty` | §1 | 她低头看着**空了的**鞋盒，一只手还伸在里面 —— 像摸口袋那样。嗓子已经没了。 |
| `H1-2-lamp-amber` | §1 | 指示灯转**琥珀色**，旁边是那只挂钟。与 `../b_converge/C1-2` 的绿灯成对。 |
| `H2-1-xeth-leaves` | §2 | 他站起来，双手抚平西装前襟 —— 一个再普通不过的整理动作。**表情完全不愤怒**，像一个合上文件夹的人。 |
| `H3-1-dawn-fence` | §3 | 黎明。天线闲置朝上，铁丝网边停着一辆车，两个人睡在里面。远、小、冷。 |
| `H3-2-empty-box-kitchen` | §3 | 空盒子摆在桌上，她一直没收起来，只是慢慢转它。 |
| `H4-1-the-receipt` | §4 | 收到回执那一刻：**一只手平按在桌上**，人一动不动，**没有在笑**。全片最不戏剧化的一秒半。 |
| `H5-1-margot-211` | §5 | 空架子、清空的房间。她收着杯子抬起头，**为自己感到困惑，半笑着** —— 她刚刚无缘无故说了一个真数字。地球部分最后一句台词。 |

实拍时用同一块面板、同一机位。
