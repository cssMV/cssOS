cssOS Developer API

Public read-only HTTP surface, scoped API keys, per-key rate limit.

Auth

Generate an API key from the dashboard (or POST /api/dev/keys while signed in). Keys look like cssos_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx and are returned once.

curl https://cssos.app/api/v1/persons \
  -H "Authorization: Bearer cssos_xxxxxxxx..."

Rate limit

Default 60 requests / minute per key (token bucket). When exceeded the API returns 429 with a Retry-After header.

Endpoints

GET /api/v1/persons — list recent person profiles. Query: limit (1–100).

GET /api/v1/persons/:id — full profile.

GET /api/v1/persons/:id/codex — codex object.

GET /api/v1/mvs/:id — MV row.

GET /api/v1/works/:id — work row.

Key management

POST /api/dev/keys — body {name, scopes?: ["read"|"write"|"admin"]}. Returns plaintext key once.

GET /api/dev/keys — list your keys (masked).

DELETE /api/dev/keys/:id — revoke.

Errors

{ "ok": false, "code": "API_KEY_REQUIRED" }
{ "ok": false, "code": "INVALID_API_KEY" }
{ "ok": false, "code": "SCOPE_FORBIDDEN", "required": "read" }
{ "ok": false, "code": "RATE_LIMIT", "retry_after": 12 }
