## Part D — 7 天作战节奏

```
Day -2 → 跑 cssOS 5 个 seed,拿到 5 个成品 MV
Day -1 → CapCut 把成品 MV 嵌入真人钩子,出 5 条 final 视频
Day 0  → 发 organic (TikTok 主账号),5 条间隔 6h 发
Day 1  → 看 24h organic 数据,挑表现最好的 1 条
Day 2  → TikTok Ads 上线,只投挑出来那 1 条,$20/天
Day 3  → 看 CPI,< $3 → 加预算到 $50;> $5 → kill 换下一条
Day 7  → 总结哪条钩子赢,只保留赢家,加预算到 $100/天
```

**关键 KPI 看板**：

| 指标 | 第 1 天 目标 | 第 7 天 目标 | 警戒线 |
|---|---|---|---|
| TestFlight + App Store 装机 | 50 | 300 | < 30 = 素材不行 |
| 三平台总 views | 5,000 | 50,000 | < 2K = hook 不够 |
| App Store conversion | 8% | 15% | < 5% = 截图要改 |
| Cost per Install (CPI) | n/a (organic) | $1.5–$3 | > $5 = 砍预算 |
| 自然搜索 "cssOS" 频次 | 10 | 200 | 这个增长最珍贵 |

## Part E — 广告视频结尾字幕 CTA（CapCut 用）

> 2026-05-20 复盘补充：$40 测试投放拿到 5273 views / 1857 likes（35% like 率，极高）
> 但 **0 注册 0 登录**。漏斗断在"看完成品 → 行动"。补两个 CTA 闭环：
> ① 落地页强制 CTA（已上线，进 `?cssMV=` 看完弹"你也能做一个"）
> ② 广告视频结尾 end-card（本节）。

### 黄金 5 法则
1. **时机**：高潮后 / 最后 2–3 秒出，别太早（毁完播率）。
2. **一屏一事**：只说一个动作 ——"去做一个"。不要又赞又关注又下载。
3. **降门槛 > 吹功能**："免费 3 次 / 无需信用卡 / 30 秒" 胜过 "AI 驱动 60+ 引擎" 10 倍。
4. **动词开头**：Make / Try / 做 / 试。
5. **三处一致**：字幕 + 口播 + 主页链接 → "link in bio"。

### 通用 End-Card（套任何题材）

**英文**（3 行，逐行 0.8s 弹出）
```
You just watched AI make this.        ← 大字 白
One sentence → a full MV in 30s.      ← 中字 绿
▶ Make yours free — link in bio       ← CTA 胶囊
```

```
这支 MV，AI 30 秒做的。
一句话 → 整支音乐视频。
▶ 免费做一支 · 主页链接
```

**双语极简**

### CapCut 落地参数（直接照抄）

| 参数 | 值 |
|---|---|
| 字体 | 思源黑体 Bold / Montserrat ExtraBold |
| 主标颜色 | `#FFFFFF` |
| 副标颜色 | `#00F5A0`（cssOS 绿） |
| CTA 胶囊 | 底 `#00F5A0` · 字 `#001B14` |
| 描边 | 黑 4–6px |
| 阴影 | Y+4 模糊 8 黑 50% |

**动画**：主标向上滑入+淡入 0.3s → 副标延迟 0.4s 跟上 → CTA 胶囊弹性放大 (0.9→1) + 微呼吸 loop。

**时间轴（30s 正片）**
```
0:00–0:27  正片高潮
0:27–0:30  end-card 叠最后一帧（画面降速 50% + 轻暗角）
整条       右上角常驻 "cssOS" + 主页链接水印（10% 不透明）
```

**口播（结尾 2 秒，配字幕）**：EN *"Make your own — free. Link in bio."* / 中 *"免费做一支，主页链接。"*

```sql

FROM share_cta_events
WHERE created_at > now() - interval '3 days'
GROUP BY utm, action ORDER BY utm;
```
